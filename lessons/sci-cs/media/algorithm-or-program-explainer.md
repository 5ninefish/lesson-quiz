## Narration

Ever followed a list of steps to make something? Native Hawaiian weavers have done it for generations.

Lauhala is the dried leaf of the hala tree, woven into mats, baskets, even sails.

To make a rose, a weaver goes step by step: leaf, strip, fold and roll, rose.

A sequence of steps that finishes a task? That's an algorithm. And anyone can follow one, a person or a machine.

Now let's look at an algorithm a computer can execute.

A program is an algorithm written so a computer can run it. Under When run, each block is one instruction.

Press Run, and the tablet does every step on its own. Nobody has to choose what comes next.

But what if we swap two steps? Now the path goes wrong.

Is it still an algorithm? Yes. Just a wrong one.

So, the steps come first. A program is steps written so a computer can run them.
